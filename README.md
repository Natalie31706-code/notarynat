# Notary

### Project Overview
A responsive legal services website built with HTML5 and CSS3, designed to present notary and legal services through a clean and professional interface. The website allows visitors to explore different legal practice areas, learn more about the services, view customer testimonials, and book an appointment online.


### Live Demo
[View the Website](https://glintnat-6jsb.vercel.app/)
### Video Preview
[Watch the Website Demo](https://youtu.be/0yQqEemLfcU)


## Key Features

- View legal and notary services
- Browse different legal practice areas
- Book an appointment online
- Enter name and email information
- Select an appointment date
- View information about the service
- Display customer testimonials
- Contact section
- Responsive design
- Clean and professional user interface

## Installation
1. Clone the repository
```bash
git clone https://github.com/Natalie31706-code/notarynat.git
```

2. Navigate to the project folder
```bash
cd notarynat
```

3. Open index.html in your browser.

## Project Purpose
This project was built to practice HTML and CSS fundamentals while creating a responsive and professional legal services website. It demonstrates how to structure a web page, create responsive layouts, design service sections, build an appointment form, and create an intuitive interface for presenting legal and notary services.
